# Руководство по обучению нейронной сети

## Обзор

Система обучения реализована в файле `Training.ts` и интегрирована в основное приложение. Она использует алгоритм поиска кратчайшего пути (Дейкстра) для нахождения оптимальных соединений между входными и выходными нейронами, а затем уменьшает веса этих соединений для улучшения производительности.

## Принцип работы

1. **Поиск пути**: Для каждого активного входного нейрона находится кратчайший путь к целевому выходному нейрону
2. **Обучение**: Веса соединений в найденных путях уменьшаются на величину, определяемую скоростью обучения
3. **Сохранение**: Обученные веса сохраняются в JSON файл для последующего использования

## Доступные функции в консоли браузера

### Основные функции обучения

```javascript
// Обучить на одной цифре
trainDigit(inputDigit, expectedOutput)
// Пример: trainDigit(5, 5) - обучить распознавать цифру 5

// Обучить на всех цифрах (0-9) за несколько эпох
trainAll(epochs)
// Пример: trainAll(5) - 5 эпох обучения на всех цифрах

// Тестировать одну цифру
testDigit(digit)
// Пример: testDigit(3) - проверить, как сеть распознает цифру 3

// Тестировать все цифры и показать точность
testAll()
// Возвращает точность от 0 до 1
```

### Сохранение и загрузка весов

```javascript
// Сохранить текущие веса в JSON файл
saveWeights()
// Сохраняет в localStorage и предлагает скачать файл

// Загрузить веса из localStorage
loadWeights()
// Возвращает true при успешной загрузке
```

### Утилиты

```javascript
// Получить статистику обучения
getTrainingStats()
// Возвращает: { trainingSteps, learningRate }

// Установить скорость обучения (0.001 - 1.0)
setLearningRate(0.2)

// Быстрое демо обучения
quickDemo()
// Автоматически тестирует, обучает и сохраняет веса
```

### Визуализация

```javascript
// Установить цифру для отображения
setDigit(7)
// Показывает цифру 7 и подсвечивает пути к соответствующему выходу

// Показать путь между конкретными нейронами
showPath(fromX, fromY, fromZ, toX, toY, toZ)

// Очистить подсветку путей
clearTrace()
```

## Пример использования

```javascript
// 1. Проверить точность до обучения
console.log('Точность до обучения:');
testAll();

// 2. Обучить сеть
console.log('Начинаем обучение...');
trainAll(10); // 10 эпох

// 3. Проверить точность после обучения
console.log('Точность после обучения:');
testAll();

// 4. Сохранить обученные веса
saveWeights();

// 5. Тестировать отдельные цифры
for (let i = 0; i <= 9; i++) {
    testDigit(i);
}
```

## Формат файла весов

Веса сохраняются в JSON файле со следующей структурой:

```json
{
  "weights": [
    {
      "sourceX": 0,
      "sourceY": 0,
      "sourceZ": 0,
      "targetX": 1,
      "targetY": 1,
      "targetZ": 1,
      "weight": 8.5
    }
  ],
  "metadata": {
    "version": "1.0",
    "createdAt": "2024-01-01T12:00:00.000Z",
    "totalTrainingSteps": 150,
    "learningRate": 0.1
  }
}
```

## Параметры обучения

- **Скорость обучения (Learning Rate)**: По умолчанию 0.1. Определяет, насколько сильно уменьшаются веса при каждом шаге обучения
- **Минимальный вес**: 0.01. Веса не могут быть меньше этого значения
- **Файл весов**: По умолчанию 'neural_weights.json'

## Советы по использованию

1. **Начните с малого**: Попробуйте `trainAll(1)` для од��ой эпохи
2. **Мониторьте прогресс**: Используйте `testAll()` между эпохами обучения
3. **Сохраняйте веса**: Регулярно вызывайте `saveWeights()` для сохранения прогресса
4. **Экспериментируйте**: Попробуйте разные значения скорости обучения с `setLearningRate()`
5. **Визуализируйте**: Используйте `setDigit()` для наблюдения за изменениями в путях

## Быстрый старт

Для быстрого знакомства с системой обучения выполните в консоли:

```javascript
quickDemo()
```

Эта функция автоматически протестирует сеть, обучит её и сохранит результаты.

// Быстрое демо
quickDemo()

// Пошаговое обучение
trainAll(10)        // Обучить 10 эпох
testAll()           // Проверить точность
saveWeights()       // Сохранить веса
loadWeights()       // Загрузить веса

// Тестирование отдельных цифр
testDigit(5)        // Проверить цифру 5
setDigit(7)         // Показать цифру 7 с путями
