# Neuro - 3D Neural Network Visualization with Training

Интерактивная 3D визуализация нейронной сети для распознавания цифр с системой обучения на основе поиска кратчайшего пути.

## Особенности

- **3D Визуализация**: Интерактивная визуализация нейронной сети с помощью Three.js
- **Распознавание цифр**: Система распознавания цифр 0-9 с использованием 7-сегментного представления
- **Обучение**: Система обучения, основанная на алгоритме Дейкстры для поиска кратчайшего пути
- **Сохранение весов**: Возможность сохранения и загрузки обученных весов в JSON формате
- **Интерактивность**: Полный набор функций для обучения и тестирования через консоль браузера

## Установка и запуск

```bash
# Установить зависимости
bun install

# Собрать и запустить проект
./start.sh
```

Или вручную:

```bash
# Собрать проект
bun run build

# Запустить локальный сервер
python3 -m http.server 8000
```

Откройте браузер и перейдите на `http://localhost:8000` для просмотра 3D визуализации.

## Архитектура

### Основные компоненты

- **Brain.ts** - Основная структура нейронной сети с алгоритмом Дейкстры
- **Neuron.ts** - Класс нейрона
- **Connection.ts** - Класс соединения между нейронами
- **Training.ts** - Система обучения с сохранением/загрузкой весов
- **index.ts** - Главный файл с 3D визуализацией и интеграцией обучения

### Структура сети

- **Входной слой (z=0)**: 10x10 матрица для представления цифр
- **Скрытые слои (z=1-9)**: Промежуточные слои обработки
- **Выходной слой (z=10)**: 10 нейронов для цифр 0-9

## Система обучения

### Принцип работы

1. Для каждого активного входного нейрона находится кратчайший путь к целевому выходному нейрону
2. Веса соединений в найденных путях уменьшаются на величину, определяемую скоростью обучения
3. Обученные веса сохраняются в JSON файл

### Основные функции (доступны в консоли браузера)

```javascript
// Обучение
trainDigit(5, 5)        // Обучить распознавать цифру 5
trainAll(10)            // Обучить на всех цифрах за 10 эпох

// Тестирование
testDigit(3)            // Проверить распознавание цифры 3
testAll()               // Проверить точность на всех цифрах

// Сохранение/загрузка
saveWeights()           // Сохранить веса в JSON
loadWeights()           // Загрузить веса из JSON

// Визуализация
setDigit(7)             // Показать цифру 7 и подсветить пути
quickDemo()             // Быстрое демо обучения
```

## Формат файла весов

```json
{
  "weights": [
    {
      "sourceX": 0, "sourceY": 0, "sourceZ": 0,
      "targetX": 1, "targetY": 1, "targetZ": 1,
      "weight": 8.5
    }
  ],
  "metadata": {
    "version": "1.0",
    "createdAt": "2024-01-15T10:30:00.000Z",
    "totalTrainingSteps": 50,
    "learningRate": 0.1
  }
}
```

## Использование

1. Откройте `index.html` в браузере
2. Откройте консоль разработчика (F12)
3. Используйте функции обучения:

```javascript
// Быстрый старт
quickDemo()

// Или пошагово:
testAll()              // Проверить точность до обучения
trainAll(5)            // Обучить 5 эпох
testAll()              // Проверить точность после обучения
saveWeights()          // Сохранить результаты
```
